# 格式契约

看板要每次长得一模一样，靠三件事：模板不改、脚本生成的部分不碰、自由文本按下面的格式写。

## 一、谁负责哪一块

| 区块 | 谁决定 | 能不能改 |
|---|---|---|
| 全部 CSS、布局、配色、明暗、交互 | `assets/template.html` | **不能改** |
| 大标题、开头两条依据说明 | 模板内写死 | 不能改 |
| 各卡片小标题、标签名、图例、说明句 | 模板内写死 | 不能改 |
| 副标题、涨粉量卡片文案、页脚 | `prepare.py` 自动生成 | 不能改 |
| 三项分数、分档、颜色 | `prepare.py` 按基准线算 | 不能改 |
| 逐篇诊断文字 | `analysis.json` | 按下面格式写 |
| 总建议 | `suggestions.json` | 按下面格式写 |
| 封面示意 HTML | `assets/snippets.md` | 复制，不要重写 |

**唯一允许追加页脚的情况**：有数据缺口要说明（例如只拿到部分封面、某几篇观看量过低）。追加在末尾，键名用 `数据缺口。`，前面五到六条一个字都不要动。

## 二、数字怎么写

| 类型 | 写法 | 例子 |
|---|---|---|
| 百分比 | 保留原始精度，不四舍五入到整数 | `22.4%`、`0.161%`、`11.16%` |
| 千分位 | 四位以上加逗号 | `48,122`、`1,240` |
| 分数 | 整数，后面跟 `/100` 或「分」 | `86 分`、`67/100` |
| 秒 | 整数 + 秒 | `16 秒` |
| 比例 | 两位小数 + `:1` | `2.53:1` |
| 倍数 | 一位小数 + 倍 | `3.4 倍` |

中英文之间、数字与中文之间**加一个空格**：`点击率 22.4% 是平台均值 11% 的两倍`。

## 三、analysis.json 的九个字段

每篇一个对象，键必须与导出表标题**逐字一致**。

```json
{
  "笔记标题": {
    "fanAlgo": [], "fanBlog": [], "fanFix": [],
    "covAlgo": [], "covBlog": [], "covFix": [],
    "conAlgo": [], "conBlog": [], "conFix": []
  }
}
```

- 每个数组 **1 到 3 条**，每条 **一句到两句**，不超过约 60 字。
- `*Algo` 只讲机制：CES 权重、流量池闸门、点击率红线、停留时长、搜索索引。**必须至少出现一个本篇的真实数字。**
- `*Blog` 只讲打法：封面公式、标题结构、正文套路、追剧感、人设。
- `*Fix` **必须以 `保持：` 或 `修改：` 开头**（全角冒号）。分数 ≥40 用「保持：」，<40 用「修改：」。一条讲要保住什么，一条讲怎么更好。
- 两个视角说同一件事就是没写好，重写。
- 观看量低于 100 的笔记，`*Algo` 直接写「样本量不足，无法评估」，不要硬编原因。

## 四、suggestions.json

3 到 5 条，`render.py` 会强制校验。

```json
[{
  "h": "动作句，不带句号",
  "t": "触发数字，关键值用 <b></b> 包住",
  "p": ["做法一。", "做法二。"],
  "s": "算法依据：…。实操依据：<a href=\"URL\">来源名</a> …。",
  "demo": "可选，从 snippets.md 复制"
}]
```

**`h` 标题**：一个能直接执行的动作，句子里要有动词，不带句号。
- ❌ 关注引导是当前瓶颈
- ✅ 每篇末屏写一句下期预告，主页简介改成带数字的承诺

**`t` 触发数字**：一到两句，引用看板上看得到的数字，关键值加粗。

**`p` 做法**：2 到 4 条，每条一句，句末带句号。

**`s` 依据**：固定句式，两段用句号隔开，实操依据必须带可点击链接。

```
算法依据：<机制说明>。实操依据：<a href="URL">来源名</a> <结论>。
```

只有算法依据时省略后半段，反之亦然。链接只能用 `references/` 里已有的或本轮真实搜到的。

## 五、排序规则

- 涨粉总览：默认按涨粉量降序，六个表头都可点。
- 三个分维度标签：默认按该维度分数降序，同分时按点击率、再按停留时长。
- 总建议：按杠杆从大到小，不是按发现顺序。

## 六、颜色对应

由分数自动决定，不要手动指定：**≥70 良好绿、40 到 70 中等黄、<40 较弱红**。

## 七、交付前跑一次

```bash
python3 scripts/verify.py dashboard.html
```

会检查区块是否齐全、建议条数、诊断字段、`保持：`/`修改：` 前缀、恒等式验算。有 FAIL 就不要交付。
