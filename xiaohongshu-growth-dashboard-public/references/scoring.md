# 三项指标、恒等式与百分制

> 三条基准线的来源列在算法机制参考文件里（从 SKILL.md 进），**核对日期 2026-08-17**。
> 恒等式和百分制映射是本看板自己的定义，不会过期；三条基准线会过期，
> 每次生成前按 SKILL.md 第 3 步重新搜一轮。

## 一、三个指标

| 指标 | 公式 | 回答什么问题 |
|---|---|---|
| 粉丝转化率 | 涨粉 ÷ 曝光 | 这篇整体值不值得被推 |
| 标题封面吸引力 | 观看 ÷ 曝光 | 有没有骗到点击 |
| 内容吸引力 | 涨粉 ÷ 观看 | 点进来的人愿不愿意关注 |

## 二、恒等式

```
粉丝转化率 = 标题封面吸引力 × 内容吸引力
涨粉/曝光 = (观看/曝光) × (涨粉/观看)
```

这是恒等式不是近似。看板底部会打印验算，如果对不上说明数据有问题。

**这条恒等式是整个看板的骨架**：顶部三个分数要读成「总分 + 前半段 + 后半段」，而不是三个独立指标。写总结时最有力的一句话通常是「前半段 X 分后半段 Y 分，所以总分低完全发生在某一段」。

## 三、百分制怎么映射

三档基准线全部锚定外部数据，**不用账号内部排名**。用账号内百分位会自欺欺人：一个全员不及格的账号里，最差的一篇也能排到中位数。

分段线性映射：

| 原始值区间 | 分数区间 |
|---|---|
| 0 → 中等线 | 0 → 40 |
| 中等线 → 良好线 | 40 → 70 |
| 良好线 → 优秀线 | 70 → 100（封顶） |

分档：**≥70 良好（绿）、40 到 70 中等（黄）、<40 较弱（红）**。

## 四、三条基准线的出处

**标题封面吸引力（观看/曝光）：10% / 20% / 30%**

直接来自平台数据：5% 是限流红线，约 11% 是平台均值，25% 以上算优秀。

**内容吸引力（涨粉/观看）：0.5% / 1.5% / 3.0%**

来自转粉率分级：低于 0.5% 判定为关注引导缺失，1% 及格，知识类初期 1.5% 算不错，3% 是健康值。

**粉丝转化率（涨粉/曝光）：0.05% / 0.30% / 0.90%**

行业没有这个口径的现成基准，由前两者相乘推导：

```
中等线 = 0.5% × 10%  = 0.05%
良好线 = 1.5% × 20%  = 0.30%
优秀线 = 3.0% × 30%  = 0.90%
```

## 五、口径注意事项

- 行业惯例的转粉率用 **观看量**做分母，不是曝光。两个数字通常差 4 倍以上，混用会得出相反结论。
- 曝光为 0 的笔记（刚发布还没结算）要排除在曝光类计算之外，或在页脚注明。
- 平台报的封面点击率和「观看 ÷ 曝光」算出来的值可能有几个百分点差异，因为平台定义不同。看板统一用自己算的，并在页脚说明。
- 观看量低于 100 的笔记，所有比率都不可靠，写诊断时要明说样本量不足，不要硬解读。

## 六、粉丝曲线的做法

导出表没有粉丝时间序列，只有每篇的累计涨粉。做法：

1. 问用户要**今天的真实粉丝总数**，这是唯一的锚点，无法从导出推算。
2. 从今天往回推：起点 = 今天粉丝数 − 窗口内所有笔记的涨粉之和。
3. 每篇的累计涨粉记在它的首发日。

结果**总量准确，单日时点是近似**，因为一篇笔记的涨粉是在它整个生命周期里陆续发生的，不是发布当天一次到位。看板页脚必须写明这一点。
