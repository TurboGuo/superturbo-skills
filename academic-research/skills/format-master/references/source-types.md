# Source types, APA 7 patterns with the notes that apply to every style

> 本文件中所有作者名、DOI、编号均为**合成占位符**，不是真实文献。
> Every author name, DOI and identifier in this file is a **synthetic
> placeholder**, not a real source. Do not copy one into a reference list.

Substitute the punctuation of the target style; the **fields required** are
close to constant across styles, and a missing field is a missing field
everywhere.

## Journal article, DOI
```
Author, A. A., & Author, B. B. (2023). Title in sentence case. Journal Title
    in Title Case, 45(2), 112-138. https://doi.org/10.1234/example.5678
```

## Journal article, no DOI, from a database
APA 7: no database name, no URL, unless the item is hard to find outside it.
MLA and Chicago: name the database as a second container.

## Advance online publication
`(2026). Title. Journal. Advance online publication. https://doi.org/...`

## Preprint
```
Author, A. A. (2026). Title (Version 2) [Preprint]. SocArXiv.
    https://doi.org/10.31235/osf.io/ab12c
```
**Always mark it as a preprint**, and check for a published version before
citing. Citing a preprint whose published version contradicts it is a real risk.

## Book
```
Author, A. A. (1992). Title of book in sentence case. Publisher.
```
APA 7 dropped the publisher location. ASA and Chicago keep it:
`Cambridge, MA: Harvard University Press.`

## Edited book chapter
```
Author, A. A. (2019). Chapter title. In E. E. Editor & F. F. Editor (Eds.),
    Book title (2nd ed., pp. 45-67). Publisher. https://doi.org/...
```

## Translated work
```
Bourdieu, P. (1990). The logic of practice (R. Nice, Trans.). Stanford
    University Press. (Original work published 1980)
```
In-text: `(Bourdieu, 1980/1990)`.

## Dissertation or thesis
```
Author, A. A. (2021). Title [Doctoral dissertation, University Name].
    ProQuest Dissertations and Theses Global.
```
GB/T: `[D]`. Chinese theses commonly need 学位授予单位 and 年份.

## Conference paper
```
Author, A. A. (2024, August 9-13). Paper title [Paper presentation]. Annual
    Meeting of the American Sociological Association, Montreal, QC, Canada.
```

## Working paper
```
Author, A. A. (2025). Title (NBER Working Paper No. 30001). National Bureau of
    Economic Research. https://doi.org/...
```

## Dataset
```
Author, A. A. (2020). Title of dataset (Version 1.2) [Data set]. ICPSR.
    https://doi.org/10.3886/ICPSR90001.v1
```
Cite the dataset **and** the codebook when they carry different DOIs. Many
reviewers now require the dataset citation, not a mention in the text.

## Software or package
```
Wickham, H. (2023). ggplot2: Elegant graphics for data analysis
    (Version 3.4.4) [Computer software]. https://CRAN.R-project.org/package=ggplot2
```
In R, `citation("pkg")` gives the author's preferred form. Use it.

## Government or organizational report
```
U.S. Census Bureau. (2024). Title of report (Report No. P60-xxx).
    https://www.census.gov/...
```
Group author. If the author and the publisher are the same, do not repeat it.

## Webpage
```
Author, A. A. (2026, March 14). Title of page. Site Name.
    https://www.example.com/page
```
APA 7 adds a retrieval date **only** for content designed to change.

## Legal, statutes and cases
Use Bluebook, whatever the surrounding style is. Every social science style
defers to Bluebook for legal sources.

## Interview or personal communication
APA: in-text only, no reference entry:
`(J. Zhang, personal communication, May 3, 2026)`.
Research interviews from your own data are **not** citations; they are data,
and they belong in the methods section with a participant identifier.

## Social media post
```
@someaccount. (2026, June 2). First 20 words of the post [Post]. X.
    https://x.com/exampleaccount/status/9000000000000001
```
(`@someaccount` and the id are placeholders — substitute the real handle and
the real status id.)
Archive it. Posts are deleted, and a dead link in a reference list is a problem
at proof stage.

## AI-generated content
APA 7 treats a large language model as software:
```
OpenAI. (2026). ChatGPT (Sept 2026 version) [Large language model].
    https://chat.openai.com
```
**Check the target journal's AI policy separately.** Many now require a
disclosure statement in the methods or acknowledgements rather than, or in
addition to, a citation, and a few prohibit citation of model output entirely.
