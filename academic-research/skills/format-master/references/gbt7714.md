# GB/T 7714-2015 参考文献著录规则

> **著录范例中，作者名与篇名均为占位符**（`作者甲`、`［篇名］`），只有署名为
> 费孝通、BURT R S 和国家统计局的三条是真实文献，用来演示中文专著、外文专著和
> 机构报告的格式差异。占位条目不要抄进参考文献表。

## 两种制式

### 顺序编码制 (numeric, most Chinese journals)
References numbered in order of first citation. In-text: `[1]`, `[2,5]`,
`[3-7]`, placed as superscript or inline per the journal.
```
[1] 作者甲, 作者乙, 作者丙. ［期刊论文篇名］[J]. ［刊名］, 2019, 35(4): 112-125.
[2] 费孝通. 乡土中国[M]. 北京: 生活·读书·新知三联书店, 1985: 24-31.
[3] BURT R S. Structural holes: the social structure of competition[M].
    Cambridge, MA: Harvard University Press, 1992.
[4] 作者丁. ［学位论文题名］[D]. 北京: ［学位授予单位］, 2018.
[5] 中华人民共和国国家统计局. 中国统计年鉴 2023[M/OL]. 北京: 中国统计出版社,
    2023[2026-08-25]. http://www.stats.gov.cn/....
```

### 著者-出版年制 (author-year)
Year moves directly after the author. In-text: `(作者甲 等, 2019)`, `(Burt, 1992)`.
```
作者甲, 作者乙, 作者丙. 2019. ［期刊论文篇名］[J]. ［刊名］, 35(4): 112-125.
```

## 文献类型标识 — mandatory, and the field most often missing
| 标识 | 类型 | | 标识 | 类型 |
|---|---|---|---|---|
| [M] | 专著 | | [J] | 期刊文章 |
| [C] | 论文集 | | [D] | 学位论文 |
| [R] | 报告 | | [S] | 标准 |
| [P] | 专利 | | [N] | 报纸文章 |
| [G] | 汇编 | | [A] | 析出文献 |
| [DB] | 数据库 | | [CP] | 计算机程序 |
| [EB] | 电子公告 | | | |

载体标识 appended after a slash for electronic sources: `[J/OL]`, `[M/OL]`,
`[DB/OL]`, `[EB/OL]`. An online source also carries the access date in square
brackets and the URL: `[2026-08-25]. http://...`

## 著录细则
- **Authors**: three or fewer, list all. Four or more, list the first three then
  `等` for Chinese and `et al.` for foreign-language sources.
- **Foreign names**: surname first in **full capitals**, then initials without
  periods: `BURT R S`, `IBARRA H`.
- **Separator between authors** is a comma; no `and` and no `&`.
- **Page numbers** are required for 专著 when a specific passage is cited, and
  for 期刊文章 always: `: 112-125`.
- **出版地: 出版者, 出版年** for books: `北京: 商务印书馆, 2015`.
- Periods separate the major fields; the title is followed directly by the type
  marker with no space: `社会资本研究[J].`

## 中英文混排 ordering
In 顺序编码制 the order is citation order, so no question arises. In
著者-出版年制 the common convention is **中文文献在前, 按拼音或笔画排序; 英文文献在后,
按字母排序**, and the journal's 投稿须知 will say which. Ask rather than guess —
mixing the two orderings in one list is a visible error.

## 学位论文
The **university template outranks GB/T**. Chinese universities publish a
学位论文格式规范 that fixes 字体, 字号, 行距, 页边距, 目录格式 and the reference
format, and the 答辩 committee checks against that. Ask for the template before
formatting anything.

## Tooling
- LaTeX: the `gbt7714` package, styles `gbt7714-numerical` and
  `gbt7714-plain` (author-year). `\bibliographystyle{gbt7714-numerical}`.
- Word: a GB/T 7714-2015 CSL file from the Zotero Style Repository, used with
  Zotero or with `pandoc --citeproc --csl=china-national-standard-gb-t-7714-2015-numeric.csl`.
- Verify the output against a recent issue of the target journal. Journals
  deviate from the national standard more often than they admit.
