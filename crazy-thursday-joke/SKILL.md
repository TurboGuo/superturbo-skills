# 疯狂星期四段子

## 这个 skill 干什么

Turbo 想在星期四被提醒去吃肯德基"疯狂星期四"，并且收到一个当下流行、好笑的疯四段子。你的任务就是搜一个新鲜段子，用轻松的语气发给他。

"疯狂星期四"是肯德基每周四的优惠活动，网友把它玩成了一种"反转文学"：前半段一本正经地铺垫（悲情故事、悬疑、情感、职场、科普……），结尾突然转折到"今天是肯德基疯狂星期四，谁请我吃？"或"V我50"。段子的精髓就是这个反差感。

## 两种触发场景

**场景一：Turbo 主动要段子**（说"疯四段子""来个疯四"等）。按下面的工作流程搜一个发给他即可。

**场景二：Turbo 问今天星期几**（"今天星期几""今天几号""今天是什么日子"等）。先用 `date` 命令确认今天是星期几：
- **如果今天是星期四**：不要直接干巴巴地回答"今天星期四"，而是按工作流程搜一个疯狂星期四段子，用段子来告诉他今天是星期四——先发段子，再点破"所以今天是星期四，疯狂星期四！🍗"。这是这个 skill 的彩蛋玩法。
- **如果今天不是星期四**：这个 skill 不适用，正常直接告诉他今天星期几就行，不用搜段子。

## 工作流程

1. **搜索最新段子**。用网页搜索（`WebSearch`），查询词用类似 `疯狂星期四 段子 文案 KFC 最新` 或 `疯狂星期四 v我50 文案`。想要更新鲜的内容时，可以在查询里带上当前年份。

2. **挑 1 到 2 个段子**。从搜索结果里选最好笑、最干净、反转最巧妙的。宁缺毋滥，别一次甩一堆。挑选标准：
   - 反转要利落，铺垫和"疯四"的反差越大越好
   - 干净得体，避开露骨、低俗、涉及自残或过度悲情的内容（那类段子搜索结果里很多，直接跳过）
   - 完整，不要发截断的半句

3. **用轻松俏皮的语气发给他**。开头点一句今天是疯四、可以去吃肯德基，然后把段子完整发出来。可以带一两个 KFC 相关 emoji（🍗🐔），但别堆太多。

4. **末尾附来源链接**。Turbo 的习惯是引用内容必须标来源，所以把段子出处的链接放在最后。

## 注意

- 每次都要**重新搜索**，发新鲜的段子，别老是同一个。段子是有时效性和流行度的，搜索能拿到当下正在传的版本。
- 如果 Turbo 明确说想要某个类型（悲情向、悬疑向、科普向、真诚向……），就往那个方向挑。
- 如果那天不是星期四他也来要，正常发就行，顺口调侃一句"今天不是疯四，但段子管够"之类的即可。
